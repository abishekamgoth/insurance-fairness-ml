# Medical Insurance Cost Prediction with Fairness Analysis

This project predicts medical insurance costs using machine learning and evaluates fairness across demographic groups.

## Features
- Random Forest & XGBoost models
- Fairness analysis
- SHAP explainability
- FastAPI prediction API
- Docker containerization
- ML experiment tracking

## Run API

uvicorn api.app:app --reload

Open:
http://127.0.0.1:8000/docs
## Run MLflow
mlflow ui
open:
http://127.0.0.1:5000
